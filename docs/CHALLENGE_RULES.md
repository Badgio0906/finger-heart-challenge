# F13：5段階チャレンジ

2026-09-22のユーザー指示を採用。F01〜F12のゲームを拡張する工程。Ring Survivorsのロードマップとは別管理。

- 各段階で指ハートを5回成功させる。第1〜4段階の5回目の成功後、0.8秒の結果表示を挟んで次の段階へ進む。
- 初期速度は0.65秒。段階ごとの切替間隔は0.65 / 0.55 / 0.45 / 0.35 / 0.25秒。速度の具体値は今回の仮調整値。
- 第5段階の5回目、合計25回成功で完全クリアし、切替・判定タイマーを停止する。
- 指ハート以外で止めると、その場でFailureになる。見送った指ハートは失敗にしない。
- Clearでは同じ女性が両手を上げて喜ぶイラスト。その下に「Clear」、続いて「これであなたも指ハートマスター」。
- Failureでは同じ女性が両手で顔を覆い恥ずかしがるイラスト。その下に「Failure」、続いて「指ハートマスターへの道は遠い」。
- 結果画面は自動で閉じず、「もう一度チャレンジ」で成功数0・第1段階・初期速度へ戻る。通常のタップやキー連打では再開しない。
- プレイ中のRESETも初期状態へ戻し、進行中の演出を取り消す。
- 既存の左右修正済みポーズ・入力方法・3〜7切替に1回の指ハート抽選は維持。

完了条件：5回ごとの速度変更・25回成功・1回失敗・結果保持・再挑戦を検証し、結果イラストと文言をPCおよびスマートフォン相当画面で確認して公開する。
